# perfil_consumoPT
Esta aplicação streamlit simula o perfil horário e de 15 minutos de um ponto de entrega (CPE) em Baixa Tensão Normal (BTN) utilizando as matrizes oficiais de coeficientes da E-REDES para 2026. BTN C (≤ 13.8 kVA, ≤ 7140 kWh/ano), BTN B (≤ 13.8 kVA, > 7140 kWh/ano), BTN A (> 13.8 kVA)

Endereço da aplicação: https://perfilconsumopt.streamlit.app/
